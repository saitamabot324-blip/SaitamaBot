✧ INSTALACIÓN

Clona el repositorio:

git clone https://github.com/saitamabot324-blip/SaitamaBot.git

Entra en la carpeta:

cd SaitamaBot

Instala las dependencias:

npm install

Configura tus variables de entorno en ".env".

Inicia el bot:

npm start

✧ CONFIGURACIÓN

Crea un archivo ".env" para colocar las claves de las APIs necesarias.

Ejemplo:

HIKARI_API_KEY=TU_API_KEY

IMPORTANTE: No compartas tus claves privadas ni subas tu archivo ".env" a repositorios públicos.
